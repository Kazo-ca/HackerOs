# HackerOS development

This folder documents the OS itself (code in `wasm2/HackerOs/`):
architecture, subsystems, base apps, build, tests and publishing.
What app authors need is in [`../framework/`](../framework/README.md).

Where to start: [`project-overview.md`](project-overview.md), then
[`building-and-testing.md`](building-and-testing.md) and
[`pitfalls.md`](pitfalls.md).

| Folder | Contents |

| [`adr/`](adr/README.md) | Architecture decisions (ADRs). |
| [`old/`](old/README.md) | Archives: documentation predating the rebuild plan. |
