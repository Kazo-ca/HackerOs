# Framework HackerOS : créer des apps et des sites

Ce dossier documente ce qui sert à construire **sur** HackerOS : le SDK public,
le modèle d'app, les capacités, les API `Hack*`, les formats de fichiers qu'une
app lit ou écrit, les paquets NuGet et les sites ASP.Hack ou Blazor. Le
fonctionnement interne de l'OS est dans [`../dev/`](../dev/README.md).

Par où commencer : [`sdk-developer-guide.md`](sdk-developer-guide.md) pour
écrire une première app, puis [`sdk-reference.md`](sdk-reference.md) pour la
référence complète et [`building-on-hackeros.md`](building-on-hackeros.md) pour
travailler depuis un autre dépôt.
