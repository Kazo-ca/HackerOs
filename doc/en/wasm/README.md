# HackerOS documentation

Entry point of `doc/en/wasm/`, the documentation of the HackerOS operating system (code in
`wasm2/HackerOs/`). It is the English translation of the French original in [`doc/fr/wasm/`](../../fr/wasm/README.md); both share the same folders and file names, and every change updates both. Any addition, rename or removal of a document updates this index
in the same change (see [`AGENTS.md`](../../../AGENTS.md)).

## Organization

| Folder | Contents |
| --- | --- |
| [`framework/`](framework/README.md) | Building **on** HackerOS: SDK, app model, capabilities, `Hack*` API, NuGet packages, ASP.Hack and Blazor sites. For anyone writing an app, a command, a service or a site. |
| [`dev/`](dev/README.md) | Developing **the OS** itself: architecture, subsystems, base apps, build, tests, publishing, plans and reviews of the series ([`dev/plans/`](dev/plans/README.md)), architecture decisions ([`dev/adr/`](dev/adr/README.md)), pitfalls ([`dev/pitfalls.md`](dev/pitfalls.md)) and archives ([`dev/old/`](dev/old/)). |
| [`memory/`](memory/README.md) | Project memory: state of the series, working conventions, next ADR number, historical notes. |
