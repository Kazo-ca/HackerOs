# KazoOS social preview

The image GitHub shows when a link to the repository is shared (1280x640).

- `kazoos-social-preview.svg`: the source. Edit this file.
- `kazoos-social-preview.png`: the rendered image, uploaded in the repository
  **Settings > General > Social preview** on GitHub. GitHub does not read it from
  the repository: upload it again after every change.

The terminal shows the version of `wasm2/KazoOs/build/Versions.props` at the
time the image was made (2.2.2). To render the PNG, open the SVG in a browser at
1280x640 and take a screenshot, or use any SVG renderer that has the Inter and
DejaVu Sans Mono fonts.
