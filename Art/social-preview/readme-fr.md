# Aperçu social de KazoOS

L'image que GitHub affiche quand on partage un lien vers le dépôt (1280x640).

- `kazoos-social-preview.svg` : la source. C'est ce fichier qu'on modifie.
- `kazoos-social-preview.png` : l'image rendue, téléversée dans le dépôt GitHub,
  **Settings > General > Social preview**. GitHub ne la lit pas dans le dépôt :
  il faut la téléverser de nouveau après chaque changement.

Le terminal affiche la version de `wasm2/HackerOs/build/Versions.props` au moment
où l'image a été faite (2.2.2). Pour rendre le PNG, ouvrir le SVG dans un
navigateur à 1280x640 et faire une capture, ou utiliser un outil de rendu SVG qui
a les polices Inter et DejaVu Sans Mono.
