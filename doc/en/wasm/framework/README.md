# HackerOS framework: building apps and sites

This folder documents what is used to build **on** HackerOS: the public SDK,
the app model, capabilities, the `Hack*` APIs, the file formats an app reads or
writes, the NuGet packages and the ASP.Hack or Blazor sites. The internals of the
OS are in [`../dev/`](../dev/README.md).

Where to start: [`sdk-developer-guide.md`](sdk-developer-guide.md) to
write a first app, then [`sdk-reference.md`](sdk-reference.md) for the
complete reference and [`building-on-hackeros.md`](building-on-hackeros.md) to
work from another repository.
