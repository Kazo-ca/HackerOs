# Développement de l'OS HackerOS

Ce dossier documente l'OS lui-même (code dans `wasm2/HackerOs/`) :
architecture, sous-systèmes, apps de base, compilation, tests et publication.
Ce qui sert aux auteurs d'apps est dans [`../framework/`](../framework/README.md).

Par où commencer : [`project-overview.md`](project-overview.md), puis
[`building-and-testing.md`](building-and-testing.md) et
[`pitfalls.md`](pitfalls.md).
