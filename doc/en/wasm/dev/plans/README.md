# Series plans and reviews

Plans validated by Benoit and end-of-series reviews. The current state of the project is
summarized in [`../../memory/README.md`](../../memory/README.md).

| Document | Role |
| --- | --- |
| [`ecosystem-rebuild-plan.md`](ecosystem-rebuild-plan.md) | Ecosystem rebuild plan validated on 2026-10-10: `Hack*` file API, manifest as a C# class, settings and logs as files, `/proc` and `/dev`, complete shell, recycle bin, dangerous permissions, base apps. **Read first.** |
| [`execution-isolation-plan.md`](execution-isolation-plan.md) | Phase 5, validated and completed on 2026-10-16 (final verification `rebuild/5-final`): optional per-process CPU and memory measurement, "Not responding", clean shutdown (`StopRequested`, `CheckpointAsync`, escalation), headless processes in Web Workers; `rebuild/5-*` work items and migration of existing apps (ADR 0066 to 0071). |
| [`execution-followups-plan.md`](execution-followups-plan.md) | Follow-ups to phase 5, **validated on 2026-10-17**, to be carried out after the wasm v3 migration: per-process limits, OOM killer disabled by default, remote event gateways, "The application is not responding" box, heavy tasks in a worker (`HackBackground.RunAsync`) then a trial of windows in a worker, `HackerOs.Server` served as WebAssembly with only its API on the server side, cross-origin isolation (COOP/COEP); `exec/*` work items and Benoit's answers; branch `exec/base` created on 2026-10-18, ADR 0124 to 0135 written, Benoit's answers to questions E1 to E4 (section 6.1); **series completed on 2026-10-18** by `exec/10-final` (SDK 1.2, final verification in section 11), then merged into `main` the same day. |
| [`desktop-and-context-menu-plan.md`](desktop-and-context-menu-plan.md) | Desktop icons, file control and central context menu, **validated on 2026-10-19**: SDK reduced to contracts (the OS provides the rendering at runtime, the explorer registers as provider of the file control and its dialogs), multi-level context menu provided by the OS (`Menus.Attach`), menu entries registered by apps at installation (`[RegisterFileContextMenu]`, placement, `shell.context-menu` capability), desktop on `~/Desktop` as a grid with positions and `.desktop` files, SDK 2.0 which removes `FileView`; answers Q1 to Q22, ADR [0148](../adr/0148-sdk-contracts-and-os-provided-controls.md) to [0152](../adr/0152-desktop-icons.md) written, work items 0 to 6 all done ( [0155](../adr/0155-file-control-implementation-adjustments.md) for 3, [0157](../adr/0157-file-dialogs-show-the-file-control.md) for 3b, [0158](../adr/0158-replaceable-file-provider-implementation-adjustments.md) for 3c, [0159](../adr/0159-app-menu-entries-implementation-adjustments.md) for 4, [0160](../adr/0160-desktop-implementation-adjustments.md) for 5, [0161](../adr/0161-sdk-2-0-implementation-adjustments.md) for 6); final verification of the series in §13. |
| [`asp-hack-plan.md`](asp-hack-plan.md) | Web phase, validated on 2026-10-16 (branch `web/base`): internal ASP.Hack sites in the style of ASP.NET MVC, interactive Blazor sites, static sites managed by `hackwebd` and Web Server Manager, HTML rendering isolated from the browser, `file://`, detached windows; `web/*` work items (ADR 0073 to 0078). |
| [`wasm-v3-completion-plan.md`](wasm-v3-completion-plan.md) | End of the wasm v3 migration, **validated and completed on 2026-10-17** (branch `v3/base`): what remains of `doc/en/wasm/dev/plans/wasm-v3-migration-analyse.md` as `v3/*` work items (windows, intents, services, SDK versions and packages, backup, sensitive settings, sync, server relays, Hack Paint and theme editor, localization, accessibility, trimming, freezing SDK 1.0); **no game on this repository** (ADR 0135). |
| [`wasm-v3-final-status.md`](wasm-v3-final-status.md) | Review of the wasm v3 migration (work item `v3/16-final`, 2026-10-17): the sixteen work items delivered, the final verification of `v3/base` (build, all suites, trimmed publication, SDK 1.0 compatibility, three hosts), known gaps, questions still unanswered and pre-existing red tests; supplemented by the verification of `v3.1/base` after the publication of SDK 1.1. |
| [`v3-1-series-plan.md`](v3-1-series-plan.md) | Series v3.1 (branch `v3.1/base`, 2026-10-17): gaps of the v3 migration fixed before the follow-ups of step 5; restoration of window geometry (ADR 0116), window title set by the app and publication of SDK 1.1 (ADR 0117), merge of `v3/base` (per-user associations, `passwd`), branches, dependencies and merge bar. |
| [`wasm-v3-migration-analyse.md`](wasm-v3-migration-analyse.md) | Analysis of the wasm v3 migration (starting point of the end-of-migration plan). Historical. |
